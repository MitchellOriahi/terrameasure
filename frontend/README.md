# TerraMeasure frontend

The new TerraMeasure web app: a map-first land intelligence tool. Draw a
piece of land anywhere in the US and get a GO / CAUTION / NO-GO verdict,
measurements with error bounds, and terrain layers, in about a minute.

Everything here is preliminary and uncertified. A licensed surveyor seals
real surveys; we make the first look fast and free.

## Running it in development

You need two terminals: one for the Python backend, one for this app.

Terminal 1, the backend (from the project root, not this folder):

```bash
venv\Scripts\activate
python -m uvicorn api.server:app --reload --port 8000
```

Terminal 2, the frontend (from this `frontend/` folder):

```bash
npm install        # first time only
npm run dev        # then open http://localhost:5173
```

How they connect: in development the browser calls `/api/...`, and Vite
(see `vite.config.ts`) quietly forwards those requests to the backend on
port 8000. In a production build the app talks directly to the deployed
API instead; set `VITE_API_URL` at build time to point somewhere else.

## Building for production

```bash
npm run build      # type-checks everything, then bundles into dist/
npm run preview    # serves the dist/ folder locally to sanity-check it
```

`npm run build` fails on any TypeScript error on purpose. That is your
safety net; do not work around it.

## How the pieces fit

```
src/
  main.tsx                entry point, mounts <App/>
  App.tsx                 providers (query cache, map handle, router) + routes
  index.css               the ENTIRE design system: colors, fonts, glass look

  lib/
    api.ts                backend URL, response types, fetch helpers
    geo.ts                area/perimeter math + number formatting
    verdict.ts            score, GO/CAUTION/NO-GO, earthwork cost range
    utils.ts              cn() class-merging helper

  store/
    appStore.ts           Zustand: basemap, layers, draw mode, survey result

  hooks/
    useSurvey.ts          runs a survey (TanStack mutation + cold-start timer)
    useIsMobile.ts        "are we on a phone?" as a reactive hook

  components/
    ui/button.tsx         the one Button (shadcn-style variants)
    ui/sheet.tsx          THE mobile bottom sheet primitive (peek/half/full)
    TopBar.tsx            wordmark, search, draw tools, basemap, 3D, nav
    SearchBox.tsx         debounced geocode search, flies the map
    LayersPanel.tsx       overlay toggles (desktop panel + mobile sheet)
    MobileBottomBar.tsx   phone action bar: Layers / Survey / Saved
    map/
      basemaps.ts         all tile/style URLs in one place
      MapView.tsx         the MapLibre map + declarative overlay layers
      DrawTools.tsx       terra-draw wiring (emits vertices, renders nothing)
    results/
      ResultsContent.tsx  verdict, cost, dial, metric rows, chart
      ScoreDial.tsx       SVG score gauge
      MetricRow.tsx       one "value ± error" row
      ElevationChart.tsx  SVG elevation profile with hover readout

  pages/
    MapPage.tsx           composes the whole map screen
    PlaceholderPage.tsx   shared "coming in this rebuild" screen
```

## Where state lives (the one rule)

- Map and UI state (which basemap, which layers are on, is a panel open,
  the drawn polygon) lives in the Zustand store, `store/appStore.ts`.
- Server data (survey responses, geocode results) is fetched through
  TanStack Query. The finished survey is mirrored into the store so every
  panel can read it without prop-drilling.

## Design language, in one paragraph

Warm near-black charcoal surfaces, one emerald/forest green accent, Inter
for UI text, JetBrains Mono ONLY for numeric measurement values. Panels
float over the full-bleed map using the `.glass` class from `index.css`
(blur, hairline border, soft shadow, 14px radius). Verdict colors (green,
amber, red) always ship with a text label, never color alone. And two
project rules are sacred: never show a bare number without its error
bound, and every results view carries "Preliminary and uncertified".

## PWA

`vite-plugin-pwa` (configured in `vite.config.ts`) makes the app
installable on phones. Icons are generated by `scripts/make-icons.mjs`
(plain Node, no image libraries); rerun it if you change the brand mark.
